# Build Log

This log reconstructs the INSTINCT project from known dated checkpoints, retained measurements, photographs, and project discussions.

It is intentionally **not presented as a perfect daily laboratory notebook**. Dates are precise where the record supports them; work between checkpoints is grouped into phases. This preserves an honest timeline while still documenting the engineering decisions, problems, and progress that occurred during the build.

## Timeline

| Date / phase | Milestone |
|---|---|
| June 16 | Project kickoff, kit ordered, GitHub/OpenRocket setup |
| June 24 | Manufacturer instructions and OpenRocket baseline established |
| June 26–27 | Kit arrival, inventory, dry fit, measurements |
| Late June–mid July | Surface preparation, motor mount, structural assembly, epoxy work |
| Mid–late July | Fins, coupler/payload work, paint/finish, motor-retention decision |
| Late July–early August | Rail buttons, retainer, final assembly, launch logistics |
| August 3–5 | As-built mass/CG calibration and OpenRocket finalization |
| August 8 | Successful F15-4 launch and recovery |
| August 10 | Launch-day simulation reconstruction and GitHub closeout |
