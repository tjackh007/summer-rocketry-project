# Portfolio / Résumé Summary

## One-line project description

Independent summer aerospace project building, calibrating, simulating, and flight-testing a LOC Graduator model rocket using measured mass/CG and OpenRocket wind-sensitivity analysis.

## Résumé bullet options

**Technical version**

- Built and flight-tested a LOC Graduator rocket; calibrated an OpenRocket as-built model using measured **462 g dry mass** and **60.5 cm CG**, evaluated F15-4 performance across wind scenarios, and successfully recovered the vehicle after launch.

**Analysis-focused version**

- Developed an as-built OpenRocket model for a 29 mm hobby rocket, incorporating measured mass properties, 1010 rail geometry, motor retention, and launch-day weather; performed sensitivity analysis showing predicted apogee variation from **216 m to 184 m** across wind cases.

**Project-management version**

- Planned and executed an independent summer rocketry project from component inventory and fabrication through simulation, launch-site coordination, flight test, post-flight analysis, and GitHub documentation.

## Interview talking points

### Why did you do it?

To stay technically active over the summer and turn theoretical aerospace coursework into a complete physical/simulation/test workflow.

### What changed from the original plan?

The project became much more focused on as-built calibration. The stock model was useful for geometry, but final mass was 12.1% higher than the manufacturer digital model.

### What was a useful mistake?

The first final weighing omitted the motor-retainer cap. Catching the discrepancy forced a clearer definition of “flight-ready dry mass” and led to a corrected 462 g calibration.

### What engineering judgment did you use?

- Used measured stage mass and CG instead of attempting to estimate every adhesive/paint contribution.
- Modeled the actual rail-button and retainer configuration rather than leaving stock launch-guidance assumptions.
- Ran wind sensitivity instead of relying on a single nominal simulation.
- Kept post-flight claims qualitative where no onboard sensor data existed.

### What would you improve next?

Add an onboard altimeter and use measured apogee/time-history data for quantitative model validation.
